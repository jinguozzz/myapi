移动端AI助手（Flutter）需求文档项目名称：MyAI Companion版本：v1.0.0文档状态：初稿目标平台：Android & iOS1. 项目概述1.1 项目背景个人使用的AI对话助手，通过接入多种大语言模型API（如DeepSeek、OpenAI、智谱等），在手机端提供统一的对话体验。用户可自由切换模型，管理对话历史。1.2 项目目标开发一款轻量、简洁的Flutter移动应用支持多模型API接入提供流畅的对话交互体验本地存储对话记录，保护隐私2. 功能需求2.1 模块一：模型管理编号	功能点	描述	优先级M-01	添加模型	填写模型显示名称、Model ID、API Base URL、API Key	P0M-02	管理请求头	支持添加自定义请求头（Header-Name / Value）	P1M-03	模型列表	展示已添加的所有模型，支持编辑和删除	P0M-04	默认模型	设置一个模型为默认，启动时自动选中	P1M-05	模型参数配置	每个模型可独立设置 Temperature、Max Tokens 等	P22.2 模块二：对话聊天编号	功能点	描述	优先级C-01	新建对话	点击"+"按钮创建新的对话会话	P0C-02	发送消息	输入文本，点击发送或回车键发送	P0C-03	流式输出	支持SSE流式响应，逐字显示AI回复	P0C-04	Markdown渲染	AI回复支持Markdown格式（代码块、列表、加粗等）	P0C-05	代码高亮	代码块支持语法高亮显示	P1C-06	复制消息	长按消息可复制内容	P1C-07	重新生成	对AI的最后一条回复重新生成	P1C-08	停止生成	流式输出过程中可点击停止	P0C-09	切换模型	在当前对话中切换使用的模型	P0C-10	上下文长度	设置对话上下文轮数（如最近10轮）	P22.3 模块三：对话历史编号	功能点	描述	优先级H-01	历史列表	展示所有历史对话（标题、时间戳）	P0H-02	删除对话	左滑删除或长按删除	P0H-03	重命名对话	修改对话标题（默认取第一条用户消息）	P1H-04	搜索对话	按标题或内容关键词搜索历史	P2H-05	导出对话	将对话导出为文本或Markdown文件	P22.4 模块四：设置编号	功能点	描述	优先级S-01	主题切换	亮色/暗色/跟随系统	P0S-02	字体大小	调整聊天界面字体大小	P1S-03	数据清除	一键清除所有对话数据	P1S-04	导入/导出配置	导入/导出模型配置（JSON格式）	P2S-05	关于	显示应用版本信息	P13. 非功能需求3.1 性能要求应用冷启动时间 ≤ 3秒对话列表滚动帧率 ≥ 60fps流式输出延迟 ≤ 500ms（首字）应用包体积 ≤ 50MB（Release）3.2 安全要求API Key 本地加密存储（使用Flutter Secure Storage）对话数据仅存储于本地（不主动上传云端）网络请求强制使用HTTPS3.3 兼容性Android 7.0 (API 24) 及以上iOS 13.0 及以上适配手机和平板（响应式布局）4. 技术选型类别	技术方案	说明框架	Flutter 3.x	跨平台开发状态管理	Riverpod 或 Bloc	推荐Riverpod，轻量灵活本地存储	Hive + SQLite	Hive存配置，SQLite存对话记录加密存储	Flutter Secure Storage	存储API Key网络请求	Dio + Riverpod	支持拦截器、取消请求SSE/流式	dart_sse 或 http + Stream	处理流式响应Markdown渲染	flutter_markdown + highlight	支持代码高亮路由管理	GoRouter	声明式路由日志	logger	调试日志5. modelId;              // 模型ID  String baseUrl;              // API Base URL  String apiKey;               // API Key（加密存储）  Map<String, String> headers; // 自定义请求头  double temperature;          // 温度，默认0.7  int maxTokens;              // 最大Token，默认4096  bool isDefault;             // 是否默认  DateTime createdAt;         // 创建时间}6.2 对话（Conversation）dartclass Conversation {  String id;                   // 唯一标识（UUID）  String title;                // 对话标题  String modelConfigId;        // 使用的模型配置ID  List<Message> messages;      // 消息列表  DateTime updatedAt;          // 最后更新时间  DateTime createdAt;          // 创建时间}6.3 消息（Message）dartclass Message {  String id;                   // 唯一标识  String role;                 // 'user' | 'assistant' | 'system'  String content;              // 消息内容  DateTime timestamp;          // 时间戳}7. API接口规范7.1 OpenAI兼容接口（标准格式）请求：textPOST {baseUrl}/chat/completionsHeaders:  Authorization: Bearer {apiKey}  Content-Type: application/json  {自定义headers...}Body:{  "model": "{modelId}",  "messages": [...],  "temperature": 0.7,  "max_tokens": 4096,  "stream": true}流式响应：Server-Sent Events (SSE) 格式7.2 适配其他厂商对于非标准接口（如某些厂商的独立格式），通过请求头或URL后缀适配预留扩展点，允许用户自定义请求体模板（P2）8. 开发计划（建议）阶段	周期	核心内容Phase 0	Week 1	项目初始化、技术选型验证、基础UI框架搭建Phase 1	Week 2-3	模型CRUD + 本地存储 + 基础聊天（非流式）Phase 2	Week 4-5	流式输出 + Markdown渲染 + 对话历史管理Phase 3	Week 6	设置页面 + 主题切换 + 加密存储Phase 4	Week 7	测试 + 优化 + 打包发布9. 风险与注意事项风险	应对措施API Key泄露	使用Flutter Secure Storage，不上传任何日志网络请求失败	增加重试机制和友好的错误提示流式解析异常	容错处理，显示已接收的部分内容大对话内存占用	限制对话最大消息数（如200条），自动截断iOS审核	确保不包含任何违规内容，明确API调用需用户自备Key10. 后续扩展方向（V2.0）支持多模态（图片识别、文件上传）语音输入/输出插件系统（联网搜索、计算器）多端同步（iCloud/Google Drive备份）预设Prompt模板（角色扮演）
