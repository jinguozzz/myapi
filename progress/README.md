# 进度跟踪

本项目用于记录开发过程中的每日进度与实际内容。

## 记录说明

- 每天在 `progress/` 目录下新建一个以日期命名的 Markdown 文件（格式：`YYYY-MM-DD.md`）。
- 每日记录包含两部分：
  - **当日内容**：当天实际完成的工作清单。
  - **详解**：对每项工作的详细说明（背景、实现方式、涉及文件、结果等）。
